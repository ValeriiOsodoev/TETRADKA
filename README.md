# Тетрадка

Бесплатный учебный сайт: математика с первого класса и алгоритмы на Python.

- **Математика** — 50 тем подряд, от цифр и счёта до производной. В каждой теме: короткое объяснение, интерактивная картинка, разобранные примеры и тренировка с задачами, которые каждый раз генерируются заново.
- **Алгоритмы** — 17 алгоритмов. У каждого: идея, пошаговая анимация с подсветкой строки кода, тренажёр (Python запускается в браузере, решение проверяется тестами) и примеры применения. Плюс страница «Основы Python».
- **Личный кабинет** — прогресс по темам и список «пора повторить». Без входа прогресс хранится в браузере, после регистрации переносится в аккаунт.

Название сайта задаётся в одном месте — `site/js/config.js` (и в `<title>` в `site/index.html`).

## Запуск

Нужен Python 3.9 или новее (на macOS подойдёт и системный).

```sh
./run.sh
```

Скрипт создаст окружение `.venv`, поставит зависимости и запустит сайт на http://127.0.0.1:8000.

То же вручную:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn server.app:app --port 8000 --reload
```

## Как всё устроено

```
server/app.py        сервер: отдаёт сайт и API аккаунтов (Starlette + SQLite)
site/                сам сайт — обычные файлы, сборка не нужна
  index.html
  css/app.css        оформление: светлая тема «тетрадь», тёмная «доска»
  js/main.js         шапка, переходы между страницами
  js/config.js       название сайта, адреса Pyodide, лимит времени
  js/store.js        аккаунт и прогресс (сервер или localStorage для гостя)
  js/dom.js          создание элементов, разметка текста, запись формул
  js/pages/          страницы: главная, математика, алгоритмы, кабинет
  js/math/           уроки (lessons1–5.js), картинки (widgets*.js), задачи (tasks.js)
  js/algo/           алгоритмы (algos1–4.js), анимация (viz.js), редактор, запуск Python
data/                база SQLite, создаётся при первом запуске
tests/               автоматические проверки
```

Фреймворков и сборщиков на стороне сайта нет: это модули JavaScript, которые браузер загружает как есть. Поправили файл — обновили страницу.

### Добавить тему по математике

Урок — объект в одном из файлов `site/js/math/lessons*.js`:

```js
{
  id: 'my-topic',                    // латиница, цифры и дефис; попадает в адрес страницы
  title: 'Название темы',
  blurb: 'Одна строка для списка тем',
  body: [
    p('Абзац. **Жирный**, ==маркер==, `код`, формула $3/4 + x^2$.'),
    rule('Правило в жёлтой рамке.'),
    w('fractionBar', { n: 3, d: 4 }, 'Подпись под картинкой.'),
    ex('Условие примера', ['Шаг 1', 'Шаг 2'], 'Ответ'),
    tip('Совет.'), warn('Частая ошибка.'),
  ],
  tasks: [                           // генераторы задач: от простых к сложным
    () => num('$2 + 2 = $', 4, 'Пояснение, которое покажется после ответа.'),
  ],
}
```

Виды задач (`tasks.js`): `num` — число, `fr` — дробь, `many` — несколько чисел, `choice` — выбор из вариантов. Формулы пишутся между знаками `$`: `a/b` — дробь, `x^2` — степень, `a_1` — индекс, `sqrt{x}` — корень, `*` — точка умножения. Порядок уроков и разделы — в `course.js`.

### Добавить алгоритм

Объект в `site/js/algo/algos*.js`: теория, код для показа (метки строк `#@имя`), функция `steps`, которая записывает шаги анимации и ссылается на эти метки, и задания с тестами. Удобнее всего скопировать соседний алгоритм и переделать. После этого добавьте его в `catalog.js`.

## Аккаунты и данные

- Регистрация — имя, логин и пароль. Почту сайт не спрашивает, поэтому **восстановить забытый пароль нельзя** — это честно написано в форме. Если понадобится восстановление, нужно добавить почту и отправку писем.
- Пароли хранятся только в виде хеша (scrypt). Сессия — случайный ключ в cookie `HttpOnly`, в базе лежит его хеш.
- Всё хранится в одном файле `data/tetradka.sqlite3`. Резервная копия — это копия файла.
- Пользователь может сам сбросить прогресс и удалить аккаунт в кабинете.

Переменные окружения:

| Переменная | Зачем |
| --- | --- |
| `TETRADKA_DB` | путь к файлу базы (по умолчанию `data/tetradka.sqlite3`) |
| `TETRADKA_SECURE_COOKIE=1` | cookie только по HTTPS — включить на боевом сервере |
| `TETRADKA_TRUST_PROXY=1` | брать адрес посетителя из `X-Forwarded-For` — если сервер стоит за nginx или Caddy |

Ограничение числа попыток входа хранится в памяти процесса, поэтому запускайте **один** процесс uvicorn (без `--workers`). Для учебного сайта этого с запасом хватает; если понадобится несколько процессов, ограничение нужно перенести в базу.

## Python в браузере

Код ученика выполняет [Pyodide](https://pyodide.org) — Python, собранный для браузера. Он работает в фоновом потоке (`py-worker.js`); если код завис, поток останавливается через 8 секунд. Сервер в этом не участвует.

Pyodide (около 10 МБ) загружается с `cdn.jsdelivr.net` при первом запуске кода. Чтобы не зависеть от чужого сервера, скачайте архив `pyodide-0.27.5.tar.bz2` со [страницы выпусков](https://github.com/pyodide/pyodide/releases), положите его содержимое в `site/vendor/pyodide/` и добавьте `'/vendor/pyodide/'` первой строкой в `PYODIDE_SOURCES` в `site/js/config.js`.

Шрифты Golos Text и JetBrains Mono подключены с Google Fonts (`index.html`). Если шрифты не загрузятся, сайт покажет системные — вёрстка от этого не ломается. Чтобы раздавать их самим, положите файлы в `site/fonts/` и замените ссылку на свой `@font-face`.

## Проверки

```sh
node tests/math-check.mjs      # все генераторы задач и вся разметка уроков
python3 tests/algo-check.py    # шаги анимаций и эталонные решения — настоящим Python
```

Проверки в браузере (нужны `pip install playwright` и запущенный сайт):

```sh
python3 tests/flow.py          # все страницы, тренировка, регистрация, перенос прогресса
python3 tests/trainer.py       # тренажёр: ошибки, тесты, подсказки, сохранение кода
```

`trainer.py` подменяет Pyodide заглушкой, которая исполняет тот же `harness.py` обычным Python, — так тренажёр проверяется без интернета.

## Выкладка в интернет

Нужен сервер, где можно держать запущенный процесс Python (VPS или платформа вроде Render, Fly.io, Railway). Статического хостинга недостаточно — на нём не будет аккаунтов (сам сайт при этом работает, прогресс хранится в браузере).

1. Скопировать проект, установить зависимости.
2. Запустить `uvicorn server.app:app --host 127.0.0.1 --port 8000` как службу (systemd).
3. Поставить перед ним Caddy или nginx с HTTPS и включить `TETRADKA_SECURE_COOKIE=1` и `TETRADKA_TRUST_PROXY=1`.
4. Настроить регулярную копию папки `data/`.
